# Короткие синтетические примеры смыслового контракта

Эти примеры не взяты из приватной встречи. Их можно включать только в подходящую стадию; не надо копировать весь набор во все запросы. Формат ответа адаптируется к реальной wire schema. Примеры задают отношения, не набор ключевых слов для hardcode.

## Альтернативные способы

Источник: «Для демонстрации подготовлю CSV или JSON; какой формат выбрать, ещё решим».
Правильно: одно обязательство подготовить демонстрационный результат, два альтернативных формата, выбор не установлен.
Неправильно: две обязательные задачи «подготовить CSV» и «подготовить JSON».

## Условный запасной способ

Источник: «Проверим загрузку. Если ускорение не поможет, попробуем пакетную обработку».
Правильно: самостоятельная проверка загрузки; отдельная условная идея пакетной обработки.
Неправильно: проверять загрузку только если ускорение не поможет.

## Имя и исполнитель

Источник: «Обсуждали с Сашей: ему стоит посмотреть ошибки»; однозначного speaker mapping для Саши нет.
Правильно: source-backed предложенная работа; назван Саша, конкретный профиль не установлен.
Неправильно: назначить задачу говорящему или любому профилю с похожим именем.

## Контекстное принятие

Источник: «Мне подготовить выгрузку и проверить её?» — «Да, сделай это».
Правильно: контекстно подтверждены конкретные действия; вопрос сам по себе до ответа не был принятым обязательством.
Неправильно: требовать обязательную фразу «я принимаю задачу» или распространять ответ на другие соседние предложения.

## Поправка количества и единицы

Источник: «Там 60 тысяч строк… нет, 16 тысяч строк в тестовом файле».
Правильно: для тестового файла исправленное количество 16 тысяч строк; прежнее число отмечено как исправленное, если сохраняется история.
Неправильно: 16 тысяч токенов; размер всей базы; оба числа как действующие факты.

## Неопределённый срок

Источник: «Сделаю к следующему обсуждению». Дата следующего обсуждения не установлена.
Правильно: due=null, относительное время сохранено текстом и имеет source evidence.
Неправильно: удалить карточку либо назначить календарную дату из сегодняшнего дня выполнения summarizer.

## Отсутствие локального контекста

В audit-пакете нет реплики, подтверждающей имя автора задачи, но оно может быть в другой части встречи.
Правильно: needs_context для проверки по полному источнику.
Неправильно: объявить назначение ложным только на этом основании.
